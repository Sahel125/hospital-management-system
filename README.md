# hospital-management-system

A Python-based hospital management system developed as part of my Computer Science studies.

## Features

- Register patients
- Register doctors
- Assign doctors to patients
- Update doctor records
- Discharge patients
- View discharged patients

## Technologies

- Python
- Object-Oriented Programming
- Modular Programming

## How to Run

1. Download the repository
2. Open the project folder
3. Run `main.py`
